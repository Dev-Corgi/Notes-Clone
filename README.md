# Apple Note Clone — UX reference library

Apple Notes iOS의 Mobbin 플로우를 BMad 작업에서 재사용할 수 있는 참고 자료로 정리합니다.

## 구조

- `docs/apple-notes/flows/` — 플로우별 Markdown, Mermaid, 스크린샷
- `docs/apple-notes/flows/README.md` — 76개 플로우 카탈로그와 수집 상태
- `docs/apple-notes/flows/_template.md` — 새 플로우 기록용 템플릿

이 자료는 관찰한 레퍼런스입니다. 제품 요구사항과 UX 결정은 이후 BMad 산출물의 `EXPERIENCE.md`, `DESIGN.md`, `SPEC.md`에 별도로 확정합니다.
